# Final local project validation checklist

The following checks apply to the **original local Unreal project** and do not need to be performed to upload the showcase files.

- [ ] Keep a separate, working backup of the complete `Animation_Prototype` directory.
- [ ] Open `L_Animation_Combat`, save the map, and compile the modified Blueprint assets.
- [ ] Verify third-person movement and camera controls.
- [ ] Verify right-mouse ADS in and out, including the crosshair visibility.
- [ ] Verify line-trace alignment, damage to enemies, and their elimination.
- [ ] Verify enemy patrol, AI perception and chase behaviour.
- [ ] Check for red debug traces, repeated Print String messages, and Blueprint runtime warnings before any final recording.
- [ ] Check the licensed assets' redistribution terms before publishing any Unreal asset files.
- [ ] Check that the README images, documentation links, and gameplay video work after the GitHub upload.
- [ ] Link the finished repository from the portfolio website.
